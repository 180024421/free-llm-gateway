大帅网关 · Mac 版（独立窗口，与 Windows EXE 同级体验）

【怎么用】
1. 解压整个文件夹到任意位置（建议放「应用程序」或「下载」）
2. 双击「启动大帅网关.command」
3. 会弹出和 Windows 一样的桌面窗口（不是浏览器）
4. 登录激活 → 粘贴上游 API Key → 点「同步到本机客户端」
5. WorkBuddy / Cursor 模型列表选「日常 · 大帅网关」

【若提示无法打开 / 已损坏】
这是 macOS 对未签名软件的拦截，按下面做一次即可：
1. 右键「启动大帅网关.command」→ 选择「打开」
2. 再点「打开」
或在「系统设置 → 隐私与安全性」里允许仍要打开。

【芯片】
- Apple Silicon（M1/M2/M3/M4）：用 runtime/arm64（当前公网包）
- Intel Mac：用 runtime/x86_64（需另打 x86_64 包）
启动脚本会自动识别。若你下载的是单架构包，请选对应芯片的 zip。

【注意】
- 用的时候请保持窗口开着
- 不要只拷贝 .command，整个文件夹要在一起
- 数据与日志保存在本目录 data/（含 desktop.log）
