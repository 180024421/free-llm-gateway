大帅网关 · Mac 版

1. 下载 zip → 双击解压
2. 右键「大帅网关.app」→「打开」→ 再点「打开」
3. 登录 → 粘贴卡密 → 粘贴 API Key →「导入并同步客户端」
4. WorkBuddy / Cursor 选「日常 · 大帅网关」

想更稳：多申请几个 Key（魔搭 / 智谱 / 硅基），都粘到「上游渠道」再同步一次。

注意：
- 整个文件夹要在一起，别只拷启动脚本
- 用的时候窗口别关（关窗口一般会缩到菜单栏「大帅」）
- 升级：先备份旧目录 data/，再解压新包，把 data/ 拷回去

打不开：系统设置 → 隐私与安全性 → 仍要打开
