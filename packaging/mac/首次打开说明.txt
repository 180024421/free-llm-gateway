大帅网关 · Mac 版（独立窗口，与 Windows EXE 同级体验）

【有没有 dmg？】
没有单独的 .dmg 安装器。zip 里自带「大帅网关.app」+「启动大帅网关.command」，解压即用。

【傻瓜步骤】
1. 下载：http://111.229.202.251/dashuai-gateway/大帅网关-mac-arm64.zip
2. 双击 zip 解压，得到文件夹「大帅网关-mac-arm64」（可整夹拖进「应用程序」）
3. 优先：右键「大帅网关.app」→「打开」→ 再点「打开」
   或：右键「启动大帅网关.command」→「打开」（会自动再打开 .app）
4. 第一次可能准备环境十几秒 → 弹出网关窗口（看 Dock 里的「大帅网关」）
5. 注册/登录 → 兑换卡密 → 上游渠道粘贴自己的 API Key →「保存并同步客户端」
6. 关掉大窗口也没关系：看屏幕右上角菜单栏「大帅」→ 显示窗口 / 退出网关
7. WorkBuddy / Cursor 选「日常 · 大帅网关」

【升级（保留配置）】
用户配置在本目录 data/（API Key、登录态、端口等）。
升级时请把旧文件夹的 data/ 整个拷到新解压目录，再启动。
切勿在 Finder 里对整个文件夹点「替换」（会清掉旧 data）。
详见同目录「升级保留配置.txt」。

【窗口与终端】
- 用 .command 启动时：终端提示「服务已就绪」后可关掉终端
- 若弹出「是否终止进程」：请点「取消」
- 主窗口：点红色关闭或黄色缩小 → 缩到菜单栏「大帅」
- 再打开：菜单栏「大帅」→「显示窗口」，或点 Dock「大帅网关」
- 真正退出：菜单「退出网关」

【若提示无法打开 / 已损坏】
1. 右键「大帅网关.app」或「启动大帅网关.command」→「打开」→ 再点「打开」
2. 或到「系统设置 → 隐私与安全性」里允许仍要打开

【窗口一直不出现】
1. 先确认整夹是最新包（必须有「大帅网关.app」+ app/runtime/wheels），不要只换 .command
2. 浏览器试开：http://127.0.0.1:8010/ui/（能开说明服务在、只是窗口没出来）
3. 看 data/desktop.log 最后几行
4. 前台排障：
   /bin/bash -lc 'DASHUAI_FOREGROUND=1 "/Applications/大帅网关-mac-arm64/启动大帅网关.command"'
5. 旧版 data/ 可整夹覆盖到新包 data/（保留登录与 Key）

【若终端报 ARCH?: unbound variable】
说明启动脚本是旧版。请重新下载最新 zip 解压覆盖。

【芯片】
- Apple Silicon（M1/M2/M3/M4）：用当前公网 arm64 包
- Intel Mac：需另打 x86_64 包

【注意】
- 不要只拷贝 .command，整个文件夹要在一起（含 大帅网关.app）
- 数据与日志保存在本目录 data/（含 desktop.log）
- 完整教程：http://111.229.202.251/guides/dashuai-gateway-start/#mac
