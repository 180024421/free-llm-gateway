大帅网关 · Mac 版（独立窗口，与 Windows EXE 同级体验）

【有没有快速启动 / dmg？】
没有。Mac 目前只有一种包：大帅网关-mac-arm64.zip（便携文件夹）。
解压后双击启动脚本即可，效果同样是独立窗口。没有 .dmg、没有拖到「应用程序」的 .app。

【傻瓜步骤】
1. 下载：http://111.229.202.251/dashuai-gateway/大帅网关-mac-arm64.zip
2. 双击 zip 解压，得到文件夹「大帅网关-mac-arm64」（可整夹拖进「应用程序」）
3. 打开文件夹 → 右键「启动大帅网关.command」→「打开」→ 再点「打开」
4. 第一次可能准备环境十几秒 → 弹出网关窗口；终端会自动关掉（正常）
5. 注册/登录 → 兑换卡密 → 上游渠道粘贴自己的 API Key →「保存并同步客户端」
6. 关掉大窗口也没关系：看屏幕右上角菜单栏「大帅」→ 显示窗口 / 退出网关
7. WorkBuddy / Cursor 选「日常 · 大帅网关」

【升级（保留配置）】
用户配置在本目录 data/（API Key、登录态、端口等）。
升级时请把旧文件夹的 data/ 整个拷到新解压目录，再启动。
切勿在 Finder 里对整个文件夹点「替换」（会清掉旧 data）。
详见同目录「升级保留配置.txt」。

【窗口与终端】
- 终端出现「正在后台启动」后可直接关掉；不要点「终止」去杀 bash（会误杀网关）
- 若弹出「是否终止窗口中的进程」：请点「取消」，然后手动关终端即可
- 主窗口：点红色关闭或黄色缩小 → 缩到屏幕右上角菜单栏「大帅」（不占 Dock）
- 再打开：点菜单栏「大帅」→「显示窗口」；真正退出点「退出网关」

【若提示无法打开 / 已损坏】
这是 macOS 对未签名软件的拦截，按下面做一次即可：
1. 右键「启动大帅网关.command」→ 选择「打开」
2. 再点「打开」
或到「系统设置 → 隐私与安全性」里允许仍要打开。

【窗口一直不出现】
1. 打开本目录 data/desktop.log 看最后几行报错
2. 或前台模式启动（窗口会跟着终端，方便看错）：
   /bin/bash -lc 'DASHUAI_FOREGROUND=1 "/Applications/大帅网关-mac-arm64/启动大帅网关.command"'
3. 确认拷过来的是完整新包（含 app/runtime/wheels），不要只换 .command
4. 旧版 data/ 可整夹覆盖到新包 data/（保留登录与 Key）

【若终端报 ARCH?: unbound variable】
说明启动脚本是旧版。请重新下载 zip 解压覆盖，或在终端执行：
  /bin/bash "/Applications/大帅网关-mac-arm64/启动大帅网关.command"
仍不行就把整个旧文件夹删掉，重新解压新包后再双击启动。

【芯片】
- Apple Silicon（M1/M2/M3/M4）：用当前公网 arm64 包
- Intel Mac：需另打 x86_64 包

【注意】
- 不要只拷贝 .command，整个文件夹要在一起
- 数据与日志保存在本目录 data/（含 desktop.log）
- 完整教程：http://111.229.202.251/guides/dashuai-gateway-start/#mac
