# 大帅网关 Mac 便携包

## 下载

- http://111.229.202.251/dashuai-gateway/大帅网关-mac-arm64.zip
- 校验：同目录 `大帅网关-mac-arm64.zip.sha256`
- 傻瓜教程：http://111.229.202.251/guides/dashuai-gateway-start/#mac

## 有没有快速启动 / dmg？

**没有。** Mac 目前只有 zip 便携包（解压即用、独立窗口）。没有 `.dmg`、没有拖到「应用程序」的 `.app`。Windows 才是单文件 EXE。

## 怎么用

1. 下载 `大帅网关-mac-arm64.zip`（Apple Silicon / M1–M4）
2. 解压整个文件夹（可放到「应用程序」）
3. **右键** `启动大帅网关.command` → 打开（若拦截再确认一次）
4. 登录激活 → 粘贴上游 Key → 同步客户端
5. 终端会自动关掉（正常）；关主窗口会缩到菜单栏「大帅」，点「退出网关」才真正退出
