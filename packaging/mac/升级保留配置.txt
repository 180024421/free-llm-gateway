大帅网关 · Mac 升级说明（务必保留配置）

用户数据统一保存在：
~/Library/Application Support/DashuaiGateway

包括：
- config.json（端口、授权地址等）
- providers.json（你粘贴的上游 API Key）
- routers.json
- session.json（登录态 / 卡密权益缓存）
- machine-id、desktop.log 等

【推荐升级方式】
1. 先完全退出旧网关（菜单栏「大帅」→ 退出网关；或关掉旧进程）
2. 下载新 zip，解压得到新的「大帅网关-mac-arm64」
3. 打开新版「大帅网关.app」
4. 新版会自动把旧便携目录 data/ 迁入 Application Support，并创建迁移前备份
5. 确认能登录、Key 还在后，再删旧文件夹

如果数据已经位于 Application Support，以后直接替换应用目录即可，不需要再复制 data/。

【安装包本身】
- 安装包不会自带你的 config/providers/session（只有 example 模板）
- 启动脚本只有「Application Support 中还没有该文件」时才会从模板复制，不会覆盖已有配置
- 首次准备好的 runtime/venv 会留在原目录；整夹换新后需再准备一次环境（不影响 data）
- 0.5.4+ 必须带「大帅网关.app」；不要只拷贝一个 .command
- 0.5.4 默认授权地址改为直连 `http://111.229.202.251/api`（修复花生壳 DNS 登录失败）；可在「接入参数」修改
- 覆盖升级若仍报缺 cryptography：删掉安装目录里的 `runtime/venv-arm64` 再启动即可（不影响 Application Support 配置）

【不要】
- 不要只拷贝一个 .command / 不要丢掉 大帅网关.app
- 不要清空或改名 Application Support/DashuaiGateway 后再启动（等于重置）
