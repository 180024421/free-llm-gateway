大帅网关 · Mac 版（独立窗口，与 Windows EXE 同级体验）

【有没有快速启动 / dmg？】
没有。Mac 目前只有一种包：大帅网关-mac-arm64.zip（便携文件夹）。
解压后双击启动脚本即可，效果同样是独立窗口。没有 .dmg、没有拖到「应用程序」的 .app。

【傻瓜步骤】
1. 下载：http://111.229.202.251/dashuai-gateway/大帅网关-mac-arm64.zip
2. 双击 zip 解压，得到文件夹「大帅网关-mac-arm64」（可整夹拖进「应用程序」）
3. 打开文件夹 → 右键「启动大帅网关.command」→「打开」→ 再点「打开」
4. 第一次可能准备环境十几秒 → 弹出网关窗口
5. 注册/登录 → 兑换卡密 → 上游渠道粘贴自己的 API Key →「保存并同步客户端」
6. 保持窗口开着 → WorkBuddy / Cursor 选「日常 · 大帅网关」

【若提示无法打开 / 已损坏】
这是 macOS 对未签名软件的拦截，按下面做一次即可：
1. 右键「启动大帅网关.command」→ 选择「打开」
2. 再点「打开」
或在「系统设置 → 隐私与安全性」里允许仍要打开。

【若终端报 ARCH / unbound variable】
说明启动脚本是旧版。请重新下载 zip 解压覆盖，或在终端执行：
  /bin/bash "/Applications/大帅网关-mac-arm64/启动大帅网关.command"
仍不行就把整个旧文件夹删掉，重新解压新包后再双击启动。

【芯片】
- Apple Silicon（M1/M2/M3/M4）：用当前公网 arm64 包
- Intel Mac：需另打 x86_64 包

【注意】
- 用的时候请保持窗口开着
- 不要只拷贝 .command，整个文件夹要在一起
- 数据与日志保存在本目录 data/（含 desktop.log）
